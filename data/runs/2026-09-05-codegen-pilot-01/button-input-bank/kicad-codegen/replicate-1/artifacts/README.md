# Four-button digital input board

Final entry files: `attempt-03/buttons.kicad_pro`, `attempt-03/buttons.kicad_sch`, and `attempt-03/buttons.kicad_pcb`. The editable generation source is `attempt-03/generate.py`; it uses the KiCad 10.0.6 bundled pcbnew Python API for the board and writes a native schematic containing embedded standard KiCad symbols. No GUI, tscircuit, reference design, or downloaded design was used.

The board outline runs from (0,0) to (50,35) mm and has two copper layers. All routes use 0.30 mm traces with project minimum clearance and trace width set to 0.25 mm. Switch centers are 11 mm apart in a horizontal row. J1 is a standard 2.54 mm through-hole six-pin header: 1=+3V3, 2=GND, 3=BTN1, 4=BTN2, 5=BTN3, 6=BTN4. Its square pad and explicit `1:+3V3` silkscreen identify pin 1; all signals are marked.

R1–R4 use KiCad `Device:R` and `Resistor_SMD:R_0805_2012Metric`, 10 kohm. Pin 1 is +3V3 and pin 2 is its BTN signal. C1–C4 use `Device:C` and `Capacitor_SMD:C_0805_2012Metric`, 100 nF; pin 1 is BTN and pin 2 GND. SW1–SW4 use `Switch:SW_Push` and `Button_Switch_THT:SW_PUSH_6mm`, representing normally-open 6 mm momentary switches. Both footprint pads numbered 1 connect to BTN and both pads numbered 2 connect to GND. Use switches whose datasheet matches this standard terminal arrangement; no manufacturer part number was selected. Both duplicated terminal pairs are explicitly routed.

Attempt 01 is retained unchanged with 13 ERC library-configuration warnings and 15 PCB warnings. Attempt 02 adds a local symbol table, enlarges silkscreen, and trims a dangling ground rail; four capacitor silkscreen overlap warnings remain. Attempt 03 moves those labels; native ERC and DRC including schematic parity report zero violations and zero unconnected pads. Standard KiCad default ignored checks are visible in the raw reports; no violations were manually excluded. Native schematic netlist and SVG exports and PCB SVG export succeeded. `logs/attempt-03/connectivity-and-geometry.json` records an independent schematic/PCB pin-map check and dimensions. The 50.05 by 35.05 mm bounding box includes the 0.05 mm outline stroke; outline centerlines are exactly 50 by 35 mm.

Validation scripts and exact output are under `logs/attempt-01` through `logs/attempt-03`. Library tables use installed absolute KiCad library paths; edit those tables on a different machine. Embedded symbols and footprints remain editable without those paths. No manufacturing exports or physical tests were requested or performed. SVGs were exported but not visually inspected; electrical/layout validation is based on native checks and programmatic geometry/connectivity checks.
