# RC low-pass filter — tscircuit pilot

Final editable entry: `attempt-02/index.circuit.tsx`. Compiled editable schematic and routed PCB data: `attempt-02/dist/index/circuit.json`. Preview files: `schematic.svg`, `schematic.png`, `pcb.svg`, and `pcb.png` alongside circuit JSON.

J1/J2 use built-in `pinheader` with `pinrow2` footprints: two 1 mm drilled through holes on 2.54 mm pitch, square pin 1. Pin 1 is SIGNAL_IN/OUT and pin 2 is GND. R1 is a generic 1 kohm 0805 resistor; C1 is a generic nonpolar 100 nF 0805 capacitor. These are package/value selections, with no procurement-specific manufacturer part chosen. Signals are intended for 0–3.3 V.

Board: 35 × 25 mm, two copper layers. J1 and J2 centres lie 3.5 mm from the respective left/right edges. C1 is 4 mm from J2 centre. Five routed copper paths and one via connect all three required nets. Trace width is 0.25 mm. Source clearance settings are 0.25 mm; a circuit-JSON geometry audit measures minimum different-net copper clearance of approximately 0.308 mm. The audit models this design's axis-aligned rectangular pads, circular holes/vias and constant-width straight trace segments; it is not an independent manufacturing DRC.

Method: handwritten TSX primitives with local tscircuit autorouting, executed with zsh/Python command logging and the preinstalled tsci 0.0.2462 / Bun 1.3.14 environment. No GUI design work, KiCad creation, publishing or commits. `package.json` pins tscircuit. `environment.bun.lock` preserves the installed global environment lockfile (not a newly resolved project lockfile); `node_modules` is a local symlink to that installed environment. Package versions are recorded in `../logs/tool-package-versions.json`. To rebuild in this environment, enter attempt-02 and run `tsci build index.circuit.tsx --svgs --pcb-png --disable-parts-engine`.
