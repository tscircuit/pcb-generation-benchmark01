# kicad-computer-use

Create and edit the design through the KiCad GUI. Preserve native project/schematic/PCB files, custom libraries, screenshots, and an ordered action trace. Do not write design files using shell, code, plugins that generate the design, or scripting consoles. Shell may prepare an empty workspace, collect outputs, and perform post-run evaluation; it must not generate or repair the design.

Use the canonical prompt without changes. Keep the tool wrapper separately versioned here before execution. No wrapper or adapter is implemented yet. Missing capabilities are recorded as unsupported or failed, never silently substituted.
